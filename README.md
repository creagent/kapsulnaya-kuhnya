# Капсульная кухня

Интерактивный сборник: 14 заготовок, 66 блюд и салатов, 10 завтраков и 9 соусов.

[Открыть сборник](https://creagent.github.io/kapsulnaya-kuhnya/)

Сайт работает как один HTML-файл. Рецепты, поиск, памятки и версия для печати доступны без регистрации.

## Обновление

Замените `index.html` и отправьте изменения в ветку `main`. GitHub Pages опубликует обновление автоматически.

Источники рецептов и пояснения указаны в сборнике.
